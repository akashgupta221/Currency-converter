# Currency-converter
A simple and clean web-based Currency Converter built using HTML, CSS, and JavaScript.
It lets users convert between different currencies quickly and easily through an intuitive interface.

🔹 Features

Real-time currency conversion

Easy-to-use and minimal UI

Works smoothly across devices

Fast and lightweight performance

🔹 Technologies Used

HTML – structure of the app

CSS – for styling and layout

JavaScript – handles logic and dynamic updates

🔹 How It Works

Enter the amount you want to convert.

Select the currencies you want to exchange.

Click Convert to see the result instantly.

🔹 About the Project

This project was created as a small web development practice to understand how real-time data and DOM manipulation work together. It’s a great example of combining clean design with simple functionality.
